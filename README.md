# MadBuds — Godot foundation

Godot 4.x / GDScript, 2D Compatibility renderer. Open `project.godot` with Godot and press **F5**.

Controls: Left/Right aim, Up/Down power, Space launch/activate single-use Wrecking Ball, R restart.

**Status:** experimental playable prototype, not complete MB-3. Official Kush Krusher animation PNGs and manifests remain in `abvhiael/420-integrated-v0.1`; source contract remains in `abvhiael/420-integrated/mad-buds`. The placeholder geometry is not canonical art. No full Godot runtime or platform acceptance is claimed.

Keep Godot project on D: via GitHub Desktop. `.godot/` editor cache is excluded from Git.
